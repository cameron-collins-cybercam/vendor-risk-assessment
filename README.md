# Vendor Risk Assessment Project

This project demonstrates how cybersecurity Governance, Risk, and Compliance (GRC) teams evaluate third-party vendors to ensure they meet organizational security requirements.

Third-party vendors often have access to sensitive systems, customer data, or internal networks. A vendor risk assessment helps identify security risks before integrating a vendor into the organization's environment.

---

## Project Objectives

• Simulate a vendor security assessment process  
• Identify potential vendor security risks  
• Evaluate vendor compliance with security frameworks  
• Document risk mitigation strategies  

---

## Security Framework References

This project aligns with common security frameworks used in vendor risk management:

- NIST Cybersecurity Framework
- ISO 27001
- CIS Critical Security Controls
- SOC 2 Security Principles

---

## Example Vendor Evaluation Areas

- Access control policies
- Data protection practices
- Security monitoring capabilities
- Incident response processes
- Regulatory compliance
